Methodology

Scope & Strategy

In Scope

  • Browser-based webcam video capture using WebRTC.
  • Real-time hand landmark extraction in the browser via MediaPipe.
  • Data normalization (converting pixels to relative coordinates).
  • WebSocket communication between the frontend and backend.
  • On-screen text display of translated letters and common words.
  • Tracking facial expressions and body posture.

Out of Scope

  • Translating fluent, dynamic ASL sentences.
  • Sending raw video frames to the Python server.
  • Integrating specialized hardware like depth cameras or sensor gloves.
  • Building native iOS or Android mobile apps.

Execution Phases

1

Phase 1: Utilize the Google MediaPipe hand landmark detection model to extract 21 distinct coordinate points for each hand.

2

Phase 2: Convert raw 3D hand landmarks into normalized, relative coordinates to build a custom training dataset. A lightweight machine learning model is trained to recognize numerical patterns, and a Python backend applies confidence thresholds to live data streams for real-time translation.

3

Phase 3: Render the recognized letters/words onto the UI for visual feedback. A Gemini agent anticipates the user's intended next words, and the Gemini model synthesizes the text into spoken output.

Target Audience

ASL Students and Self-Learners

Tech-savvy individuals actively studying sign language who need interactive web tools for real-time visual feedback to practice at home.

Public-Facing Professionals

Retail workers and service staff who interact with the public but lack formal ASL training, needing fast, zero-installation tools to bridge communication gaps.

The Deaf Community

Native ASL signers who need frictionless, browser-based tools to share their thoughts without forcing others to download dedicated apps.
