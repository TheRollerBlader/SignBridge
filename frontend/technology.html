Project Overview

Right now, there is a massive communication gap between the Deaf community and those who don't know American Sign Language (ASL). Project Signbridge solves this by using AI to translate ASL into English text in real-time. Because it runs through a standard web browser and webcam, it instantly bridges the gap anywhere, anytime, without requiring app downloads or expensive equipment.

* Note: No generative AI was used to produce text in the original document.

Tracking & Milestones

Key Milestones

  • March 18, 2026 (Webcam on Browser): Successfully accessed the webcam via the browser and used Google MediaPipe to annotate 21 points on each hand.

  • March 19, 2026 (Train Neural Network): Trained a Neural Network using an ASL fingerspelling dataset to predict alphabetical characters from given signs.
